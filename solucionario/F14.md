## Nivel N1

### F14-N1-01 · [C] $A\mathbf{x}$ como combinación de columnas

**Enunciado.** Calcula $B_2\mathbf{x}$ con $\mathbf{x} = (3, -1)$ escribiéndolo como combinación lineal de las columnas.

**Solución.** $3\begin{bmatrix}1\\2\end{bmatrix} - \begin{bmatrix}2\\4\end{bmatrix} = \begin{bmatrix}1\\2\end{bmatrix}$. Por filas: $(3 - 2,\ 6 - 4) = (1, 2)$: el mismo resultado.

### F14-N1-02 · [K] ¿En qué espacio vive?

**Enunciado.** Para una matriz $3 \times 4$: ¿en qué $\mathbb{R}^k$ vive $\operatorname{Col}(A)$? ¿Y $\ker A$?

**Solución.** Las columnas tienen 3 componentes: $\operatorname{Col}(A) \subseteq \mathbb{R}^3$. Las incógnitas son 4: $\ker A \subseteq \mathbb{R}^4$.


## Nivel N2

### F14-N2-01 · [C] ¿Es alcanzable? (2×2)

**Enunciado.** Con $B_2$: ¿tiene solución $B_2\mathbf{x} = (3, 6)$? ¿Y $B_2\mathbf{x} = (1, 0)$?

**Solución.** $\operatorname{Col}(B_2)$ es la recta $y = 2x$. $(3, 6)$ está en ella: sí (por ejemplo $\mathbf{x} = (3, 0)$). $(1, 0)$ no: el sistema es incompatible (los rangos son 1 y 2).

### F14-N2-02 · [C] ¿Tiene solución $A\mathbf{x} = \mathbf{b}$?

**Enunciado.** Con $A$ la matriz $3 \times 4$ compartida, decide si tiene solución para $\mathbf{b}_1 = (1, 3, 2)$ y para $\mathbf{b}_2 = (1, 0, 0)$.

**Solución.** Para $\mathbf{b}_1$: $\operatorname{rg}(A) = \operatorname{rg}[A \mid \mathbf{b}_1] = 2$: compatible; de hecho $\mathbf{b}_1 = \mathbf{a}_1 + \mathbf{a}_3$. Para $\mathbf{b}_2$: $\operatorname{rg}(A) = 2$ pero $\operatorname{rg}[A \mid \mathbf{b}_2] = 3$ (queda la fila $[0\,0\,0\,0 \mid 1]$): incompatible.

## Nivel N3

### F14-N3-01 · [C] Base de $\operatorname{Col}(A)$

**Enunciado.** Halla una base de $\operatorname{Col}(A)$ y su dimensión, con $A$ la matriz $3\times 4$ compartida.

**Solución.** Base: $\{\mathbf{a}_1, \mathbf{a}_3\} = \{(1,2,1),\ (0,1,1)\}$. $\dim\operatorname{Col}(A) = 2 = \operatorname{rg}(A)$.

### F14-N3-02 · [C] Expresar las otras columnas

**Enunciado.** Escribe $\mathbf{a}_2$ y $\mathbf{a}_4$ como combinación de la base $\{\mathbf{a}_1, \mathbf{a}_3\}$.

**Solución.** $\mathbf{a}_2 = 2\mathbf{a}_1$ y $\mathbf{a}_4 = 1\mathbf{a}_1 + 2\mathbf{a}_3$. Comprobación: $2(1,2,1) = (2,4,2)$ y $(1,2,1) + 2(0,1,1) = (1,4,3)$.

### F14-N3-03 · [C] Espacio columna de una matriz 2×3

**Enunciado.** Halla una base de $\operatorname{Col}(B)$ con $B = \begin{bmatrix} 1&1&1\\1&2&3 \end{bmatrix}$. ¿Qué espacio es?

**Solución.** Pivotes en las columnas 1 y 2: base $\{(1,1),\ (1,2)\}$. Dimensión 2 en $\mathbb{R}^2$: $\operatorname{Col}(B) = \mathbb{R}^2$ (el sistema $B\mathbf{x} = \mathbf{b}$ tiene solución para todo $\mathbf{b}$).

### F14-N3-04 · [K] El error del estudiante

**Enunciado.** Un estudiante toma como base de $\operatorname{Col}(A)$ las columnas pivote de la reducida. Da un ejemplo $2\times 2$ en que eso falla y explica por qué.

**Solución.** Sea $A = \begin{bmatrix} 1&1\\1&1 \end{bmatrix}$. Su reducida es $\begin{bmatrix} 1&1\\0&0 \end{bmatrix}$ y la primera columna pivote es $(1, 0)$. Pero $\operatorname{Col}(A) = \operatorname{gen}\{(1,1)\}$ y $(1, 0) \notin \operatorname{Col}(A)$. Las operaciones por filas cambian el espacio columna; lo que se conserva son las relaciones entre columnas, por eso hay que tomar las columnas pivote de $A$: $\{(1,1)\}$.

### F14-N3-05 · [C] Imagen y núcleo de una transformación

**Enunciado.** Para $T(\mathbf{x}) = B_2\mathbf{x}$ ($T:\mathbb{R}^2\to\mathbb{R}^2$), describe la imagen y el núcleo y comprueba que $\operatorname{rg} + \operatorname{nul} = 2$.

**Solución.** Imagen: $\operatorname{Col}(B_2) = \operatorname{gen}\{(1,2)\}$, la recta $y = 2x$ (dimensión 1). Núcleo: $\operatorname{gen}\{(-2,1)\}$, la recta $x_1 + 2x_2 = 0$ (dimensión 1). $1 + 1 = 2$. La transformación aplasta la segunda recta al origen y todo el plano sobre la primera.

## Nivel N4

### F14-N4-01 · [C] Verificar rango + nulidad

**Enunciado.** Calcula rango y nulidad de $B$ y de $C$, y comprueba que suman $n$. Haz lo mismo con $A$.

**Solución.** $B$ ($n=3$): rango 2, nulidad 1; $2+1 = 3$. $C$ ($n=2$): rango 2, nulidad 0; $2+0 = 2$. $A$ ($n=4$): rango 2, nulidad 2; $2+2 = 4$.

### F14-N4-02 · [C] Datos mínimos

**Enunciado.** Una matriz $5 \times 7$ tiene rango 3. ¿Cuál es su nulidad? ¿En qué $\mathbb{R}^k$ vive $\operatorname{Col}(A)$ y qué dimensión tiene?

**Solución.** $\operatorname{nul} = 7 - 3 = 4$. $\operatorname{Col}(A) \subseteq \mathbb{R}^5$ con dimensión $3$ (un subespacio de dimensión 3 dentro de $\mathbb{R}^5$); $\ker A \subseteq \mathbb{R}^7$ con dimensión 4.

### F14-N4-03 · [K] Matrices imposibles

**Enunciado.** a) ¿Puede una matriz $3\times 5$ tener $\ker A = \{\mathbf{0}\}$? b) ¿Puede una matriz $5\times 3$ cumplir que $A\mathbf{x} = \mathbf{b}$ tenga solución para todo $\mathbf{b} \in \mathbb{R}^5$?

**Solución.** a) No: $\operatorname{rg} \le 3$, luego $\operatorname{nul} = 5 - \operatorname{rg} \ge 2 > 0$. b) No: haría falta $\operatorname{Col}(A) = \mathbb{R}^5$, es decir $\operatorname{rg} = 5$, pero $\operatorname{rg} \le 3$.

### F14-N4-04 · [D] Las columnas pivote son una base

**Enunciado.** Sea $R$ la reducida de $A$. Prueba que las columnas de $A$ correspondientes a los pivotes de $R$ son una base de $\operatorname{Col}(A)$.

**Solución.** En $R$, las columnas pivote son $\mathbf{e}_1,\dots,\mathbf{e}_r$ (independientes), y cada columna libre es combinación de ellas. Como una combinación $\sum x_j\mathbf{a}_j = \mathbf{0}$ de columnas de $A$ vale exactamente cuando $\sum x_j\mathbf{r}_j = \mathbf{0}$, las mismas relaciones valen en $A$: sus columnas pivote son independientes y cada columna libre es combinación de ellas. Luego generan $\operatorname{Col}(A)$ y son una base. $\blacksquare$


## Nivel N5

### F14-N5-01 · [D] Teorema del rango y la nulidad

**Enunciado.** Demuestra que para toda matriz $A$ de tamaño $m\times n$: $\dim\operatorname{Col}(A) + \dim\ker A = n$.

**Solución.** Sea $r$ el número de pivotes. Hay $r$ columnas con pivote y $n - r$ sin él (variables libres). Por el ejercicio N4-04, $\dim\operatorname{Col}(A) = r$. Cada variable libre aporta un vector a una base de $\ker A$ (L46), así que $\dim\ker A = n - r$. Sumando: $r + (n - r) = n$. $\blacksquare$
